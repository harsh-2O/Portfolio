# Fonts

Drop Labil Grotesk files here to enable custom typography:

- `LabilGrotesk-Regular.woff2` / `.woff`
- `LabilGrotesk-Medium.woff2` / `.woff`
- `LabilGrotesk-Bold.woff2` / `.woff`

Then uncomment the `@font-face` rules in `src/styles/fonts.css` and restore
`'Labil Grotesk'` as the first family in `--font-primary` inside `GlobalStyles.ts`.
